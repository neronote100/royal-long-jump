# 王子のロイヤル大跳躍

無料公開用の30秒ブラウザゲーム。GitHub + Cloudflare Pages / Functions / D1。
依存ライブラリなし、Canvas描画。スマホとPCに対応。

## 操作
- 開始・再挑戦：スペース、またはボタン
- 助走：スペース / タップで小ジャンプ。穴に落ちると終了
- 115〜125mの金色の踏切板：スペース / タップで大ジャンプ。端ほど上昇力アップ
- 空中：↑ / 姿勢ボタンでマントを開く、↓で水平姿勢。画面上半分・下半分のタップでも操作可能
- 黄金の靴：速度アップ、バネの勲章：上昇力アップ、羽根：風の影響アップ
- 向かい風：マントを開くと上昇、追い風：水平姿勢で加速
- 30秒を超えると失敗。着地した有効記録だけ登録可能

## ローカル実行
Node.js 24以降。

```sh
npm test
npx wrangler d1 migrations apply royal-long-jump --local
npm run dev
```
Cloudflare公開前はランキングが未設定でもゲームを遊べます。
静的ゲームだけ試す場合 `python3 -m http.server 8080 --directory public`。

## 公開準備
1. GitHubに **royal-long-jump** リポジトリを作成し、このフォルダの内容をpush。
2. CloudflareのWorkers & Pages → D1で **royal-long-jump** データベースを作成。
3. `wrangler.toml` の `database_id` を実際のIDへ置換。
4. Cloudflareログイン済みの端末でマイグレーション：

```sh
npx wrangler d1 migrations apply royal-long-jump --remote
```

5. Cloudflare PagesでGitHubリポジトリを接続。
   - プロジェクト名：`royal-long-jump`
   - フレームワーク：なし
   - ビルドコマンド：空欄
   - 出力ディレクトリ：`public`
   - ルート：リポジトリ直下
6. D1バインディング `DB` が対象DBを指していることを確認。
7. 発行された `https://royal-long-jump.pages.dev`（名称が使用済みなら別名）をnoteに掲載。

CLIでデプロイする場合：`npm run deploy`。初回はPagesプロジェクトを作成してください。
プレビュー環境にもD1を設定する場合は、本番とは別のDBを推奨します。

## ランキング
- 名前はNFKC正規化し前後空白を削除、1〜20文字。大文字・小文字は区別。
- ログインなし。同名は同一人物として扱い、他人も同名で上書き可能。
- 距離は整数cmとして保存。画面表示は小数2桁m。
- 自己ベストより1cm以上高い場合だけ更新。同点・低い記録では日時も履歴も変更しない。
- DBトリガーで初回・更新履歴を同一トランザクションに保存。
- 全員の自己ベストを保持し、上位30人を表示。履歴は直近100件を表示。
- 同距離は先に記録した人が上位。日時はサーバーUTC保存、画面は日本時間。

## 現状の限界
試作版では送信するスコアをクライアントが計算します。APIは形式・上限・送信元を検証しますが、操作履歴の再計算はなく改ざんを完全には防げません。公開規模が大きくなる場合はレート制限、サーバーでのプレイ再現検証を追加してください。
Cloudflareの無料枠を利用できますが、利用量が無料枠内に収まるかは運用時に確認してください。

## 構成
- `public/` ゲーム・UI・物理計算
- `functions/api/ranking.js` ランキング取得、履歴取得、自己ベスト登録
- `migrations/0001.sql` テーブル・更新履歴トリガー
- `test/` 物理・入力・DB更新のテスト

風は日替わり固定ではなく毎回ランダム。2〜4秒で目標風を切替、徐々に変化、風速上限・上昇力上限あり。調整値は `public/game.js` と `public/physics.js` にあります。
